# Employee Management System

A console-based Employee Management System built using Python and SQLite.

## Features

- Add Employee
- View Employees
- Search Employee
- Update Employee
- Delete Employee
- Employee Salary Report
- Input Validation
- Exception Handling

## Technologies Used

- Python
- SQLite
- SQL
